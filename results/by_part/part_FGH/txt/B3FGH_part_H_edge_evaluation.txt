Μέρος Η: Επίδραση των μεθόδων σε ακμές και χαρακτηριστικά
Εφαρμόζονται Sobel και Canny στην αρχική low-light εικόνα και στις βελτιωμένες εικόνες.

Συνοπτική αξιολόγηση ακμών:
Pipeline 1 - Gamma + stretch: μέση πυκνότητα ακμών 9.750%, μικρά components 20.66%, σημαντικά components 42.84%, Jaccard προς high 0.518.
Pipeline 2 - Median + CLAHE + unsharp: μέση πυκνότητα ακμών 9.898%, μικρά components 20.62%, σημαντικά components 42.72%, Jaccard προς high 0.399.
Pipeline 3 - Retinex sigma 15: μέση πυκνότητα ακμών 11.774%, μικρά components 23.67%, σημαντικά components 36.80%, Jaccard προς high 0.379.
Pipeline 3 - Retinex sigma 30: μέση πυκνότητα ακμών 11.879%, μικρά components 22.67%, σημαντικά components 37.51%, Jaccard προς high 0.371.
Pipeline 3 - Retinex sigma 60: μέση πυκνότητα ακμών 11.756%, μικρά components 23.49%, σημαντικά components 36.71%, Jaccard προς high 0.371.
Γενικά, μια βελτίωση εικόνας βοηθά ως προεπεξεργασία όταν αυξάνει τις συνεχόμενες και σημαντικές ακμές χωρίς να γεμίζει το edge map με πολλά μικρά θορυβώδη components.
