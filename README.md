# Project 3 - Low-light image enhancement

This folder contains the code, input images, organized results, full CSV files, and essential TXT metric summaries.

## Structure

- `code/`: all MATLAB scripts.
- `input_images/`: `*_low.png` and `*_high.png` pairs.
- `results/by_image/`: all outputs separated by image number.
- `results/by_part/`: combined outputs and complete CSV/TXT files per assignment part.

The report contains selected results and discussion; this folder keeps the full organized run for reproducibility.
