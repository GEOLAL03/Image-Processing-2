# Project 3 (Θέμα 3) - Low-light image enhancement

This folder contains the code, input images, organized results, full CSV files, and essential TXT metric summaries.

## Δομή

- `code/`:  MATLAB scripts.
- `input_images/`: `*_low.png` και `*_high.png` .
- `results/by_image/`: outputs χωρισμένα με image number.
- `results/by_part/`: όλα τα outputs και ολοκληρωμένα CSV/TXT files ανά ερώτημα.

Οι κώδικες έχουν γραφτεί για MATLAB με Image Processing Toolbox και Signal Processing Toolbox.
